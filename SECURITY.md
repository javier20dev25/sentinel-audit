| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Sentinel Audit and the integrity of security evidence very seriously.

**Please do not report security issues or vulnerability disclosures through public GitHub issues.**

If you discover a security issue, vulnerability, or secret handling bypass in Sentinel Audit, please report it through one of our monitored disclosure channels:

1. **GitHub Security Advisories:** Navigate to the "Security" tab of this repository on GitHub and select "Report a vulnerability".
2. **Security Team Email:** Send details to security@sentinel-defense.org.

### When submitting a report:

- Include steps to reproduce the issue or the unexpected behavior.
- Describe the impact and any proof-of-concept evidence.
- We will acknowledge receipt within 48 hours and work with you on remediation.
